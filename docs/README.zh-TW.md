## 文件時效

日期型計畫、開發紀錄、review 與 audit 是歷史背景，不是目前操作指令或功能保證。舊文件保留原路徑，以維持外部連結；目前驗證狀態以本入口連結的摘要為準。內部計畫、原始 receipt、提示詞與本機證據不列入新公開交付範圍。
